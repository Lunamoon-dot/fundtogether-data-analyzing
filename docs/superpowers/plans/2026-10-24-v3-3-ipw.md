# V3.3 IPW Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement and verify `ceav-m1-v3.3`, adding inverse-probability-weighted report-sensitive anchor rewards while preserving V3.2 behavior.

**Architecture:** Add a versioned `V33Config` and a small IPW accounting path that reuses the existing exact state enumeration, frozen-peer best-response search, and pure-equilibrium search. Add a separate IPW study driver for the predeclared 54-point grid, with exact moments, budget checks, causal witnesses, artifacts, CLI/API exposure, and tests.

**Tech Stack:** Python 3.12 standard library, `Fraction`, `unittest`, existing CEAV-M1 CLI/server/UI.

**Spec:** `CEAV_M1_V3_3_IPW_SPEC.md`, `ENGINE_DESIGN_V3_3_IPW.md`, `VERIFICATION_PLAN_V3_3_IPW.md`

## Global Constraints

- Keep V3.2 model version and output semantics unchanged.
- Use exact `Fraction` arithmetic; decimal is presentation only.
- Require `q0 > 0` and `q1 > 0`; `q_min = min(q0, q1)`.
- Use IPW anchor reward `mu * A * 1(report=T) / q_report` with `mu=anchor_weight`.
- Enforce cap `3*f + 6*lambda_peer + 3*mu/q_min <= reward_budget`.
- Keep three Judges, majority decision, report lock, hidden `Y/T/A`, and 432-candidate exhaustive pure search.
- Preserve every invalid budget, incomplete search, no-pure-equilibrium, and metric gate failure.
- Do not commit or include the pre-existing untracked `deep-research-report.md`.

## Review Focus

- `q0=0` or `q1=0` must fail before division; test in Task 1.
- IPW expected reward must cancel `q_report` while audit operating cost still depends on it; test in Task 2.
- Shared verification `T` must be used for exact variance/covariance; test in Task 2.
- A high IPW payment must invalidate a too-small fixed budget rather than silently increasing it; test in Task 1 and Task 3.
- Failure labels must derive from exact utility components and preserve ties; test in Task 2.
